# Lia

Dépôt d'add-ons Home Assistant de l'application **Lia Home**.

- `lia_relais/` : la fiche de l'add-on « Lia — accès de dehors », qui relie votre Home Assistant au
  relais de Lia, chiffré de bout en bout, pour piloter votre maison quand vous n'êtes pas chez vous.
  Elle ne sert qu'avec l'application Lia et un compte Lia, qui l'installe et la met à jour seule.
- `image/` : le code de l'add-on et de quoi construire son image
  (`ghcr.io/lia-home/lia-relais-addon`, amd64 et aarch64, publique).
